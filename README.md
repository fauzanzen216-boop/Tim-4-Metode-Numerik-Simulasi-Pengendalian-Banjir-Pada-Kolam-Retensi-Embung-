# Tim-4-Metode-Numerik-Simulasi-Pengendalian-Banjir-Pada-Kolam-Retensi-Embung-
Simulasi pengendalian banjir pada kolam retensi/embung menggunakan metode numerik untuk menganalisis debit masuk, debit keluar,volume tampungan, dan perubahan tinggi muka air terhadap waktu. Tujuan nya untuk mengevaluasi efektivitas kolam retensi dalam mereduksi debit puncak banjir melalui interpolasi,integrasi numerik dan persamaan diferensial.
